■ SPKLAB · Privacy

Privacy
Policy

개인정보처리방침 · 시행일 Effective date: 2026-08-09

1. 파일은 업로드되지 않습니다 · Your files never leave your computer

SPKLAB의 모든 도구(Project Scanner, Version Changer)는 100% 브라우저 안에서 동작합니다. 드래그하거나 선택한 프로젝트 파일(.aep, .aet, .prproj)은 사용자의 컴퓨터 메모리에서만 처리되며, 어떤 서버로도 전송·저장되지 않습니다. SPKLAB은 서버 자체를 운영하지 않는 정적(static) 사이트입니다.

All SPKLAB tools run entirely in your browser. Project files you drop or select are processed only in your computer's memory and are never transmitted to or stored on any server. SPKLAB is a static site with no backend of its own.

2. 수집하는 개인정보 · Personal data we collect

SPKLAB은 회원가입, 로그인, 이메일 수집을 하지 않으며 자체적으로 어떠한 개인정보도 수집하지 않습니다.

SPKLAB has no accounts, no login, and collects no personal information by itself.

3. 쿠키와 광고 · Cookies & advertising

이 사이트는 Google AdSense 광고를 게재할 수 있습니다. Google을 포함한 제3자 광고 사업자는 쿠키를 사용하여 사용자의 이전 방문 기록을 기반으로 광고를 제공할 수 있습니다. Google의 광고 쿠키 사용에 대한 자세한 내용과 맞춤 광고 해제는 Google 광고 정책 및 광고 설정에서 확인할 수 있습니다.

This site may display Google AdSense ads. Third-party vendors, including Google, use cookies to serve ads based on your prior visits. You can review Google's ad cookie practices and opt out of personalized advertising via Google's Ads Policies and Ads Settings pages linked above.

4. 호스팅 · Hosting

이 사이트는 GitHub Pages에서 호스팅됩니다. GitHub는 서비스 제공 과정에서 방문자의 IP 주소 등을 보안 목적으로 기록할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 참고하세요.

This site is hosted on GitHub Pages; GitHub may log visitor IP addresses for security purposes as part of operating the service.

5. 문의 · Contact

본 방침에 대한 문의는 GitHub 저장소 이슈로 남겨주세요.

For questions about this policy, please open an issue on the GitHub repository.

6. 변경 · Changes

방침이 변경되는 경우 이 페이지에 게시하며, 시행일을 갱신합니다.

Any changes to this policy will be posted on this page with an updated effective date.
