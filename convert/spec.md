# AEP Version Changer — 설계 문서 (2026-08-08)

## 목적
After Effects 프로젝트 파일(.aep/.aet)을 드래그앤드롭하면 저장 버전을 감지하고,
사용자가 고른 버전(업/다운그레이드)으로 패치한 사본을 다운로드해주는 **단일 HTML 웹페이지**.
모든 처리는 브라우저 안에서만 이루어진다(서버 전송 없음).

## 기술 배경 (리서치 결과)
- .aep는 빅엔디안 RIFF(RIFX) 컨테이너. `RIFX <size> Egg!` 뒤에 청크가 이어진다.
- 최상위 `head` 청크(페이로드 20바이트)에 파일 포맷 리비전이 있다:
  - `payload[1]` = 연도별 포맷 리비전: 0x5b=2020(17.x), 0x5c=2021(18.x), 0x5d=2022(22.x),
    0x5e=2023, 0x5f=2024, 0x60=2025, 0x61=2026 …
  - `payload[3]`, `payload[4..7]` = 세부 빌드 시그니처
- 구버전 AE는 이 리비전을 보고 신버전 파일을 거부한다. 따라서 이 바이트들을 목표 버전의
  시그니처로 바꾸면 구버전 AE가 파일을 연다. (오픈소스 AEP-Downgrader와 동일 원리,
  로컬 샘플 9개로 교차 검증)
- 한계: 진짜 데이터 변환이 아니므로 신버전 전용 기능은 구버전에서 무시되거나 깨질 수 있다.

## 구성
- `engine.js` — 순수 로직 (RIFX 파서 / 버전 감지 / 패처). 브라우저·Node 겸용.
- `test.cjs` — Node 테스트: 로컬 샘플 파싱, 감지 정확도, 패치 라운드트립, 원본 불변 검증.
- `template.html` — UI (다크 테마, 드롭존, 버전 선택, 다운로드).
- `build.cjs` — engine.js를 template.html에 인라인해 최종 `index.html` 생성.

## 동작 규칙
- 시그니처 검증된 버전(2022~2026)은 6바이트 전부 교체, 미검증(2020~2021)은 알려진 바이트만 교체하고 "실험적" 표기.
- 감지 실패(미지의 리비전) 시 원시 바이트를 보여주고 진행은 허용하되 경고.
- RIFX/Egg! 시그니처가 아니면 거부. 원본 파일은 절대 수정하지 않는다(사본 다운로드).
- 다운그레이드 선택 시 호환성 경고 표시. 파일명은 `원본명_AE2022.aep` 형태.
