How It
Works

An .aep file is a RIFX binary container. Near the top of the file, the head chunk stores a signature identifying which version of After Effects saved the project. Older versions of AE refuse newer files purely because of this check — so this tool rewrites those bytes (up to 6 of them) to the target version. Your project data is never touched.

.aep 파일은 RIFX 바이너리 컨테이너이고, 파일 앞부분 head 청크에 "이 프로젝트를 저장한 AE 버전" 시그니처가 들어 있습니다. 구버전 AE가 신버전 파일을 거부하는 것은 이 검사 때문이므로, 해당 바이트(최대 6바이트)만 목표 버전 값으로 교체합니다. 프로젝트 데이터는 전혀 건드리지 않습니다.

Limitations: this is not a true data conversion. Projects that use features introduced in newer versions may show warnings or lose those parts when opened in an older version. Always keep your original file and test the converted copy.

한계: 진짜 데이터 변환이 아니기 때문에, 신버전에서 새로 생긴 기능을 사용한 프로젝트는 구버전에서 해당 부분이 무시되거나 경고가 뜰 수 있습니다. 반드시 원본을 보관한 채 변환본을 테스트하세요.

Upgrading is usually unnecessary — newer versions of AE open older files natively. Everything runs locally in your browser; nothing is uploaded. Max file size ≈ 1 GB (tested with 500 MB).

업그레이드는 보통 필요하지 않습니다 — 신버전 AE는 구버전 파일을 그대로 열 수 있습니다. 모든 처리는 브라우저 안에서 끝나며 파일은 어디로도 전송되지 않습니다. 파일당 최대 약 1GB (500MB까지 검증).
